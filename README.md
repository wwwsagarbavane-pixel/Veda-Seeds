# Veda Seeds - Seed Sciences

Better Seeds, Brighter Tomorrows. Official Landing Page for **Veda Seeds**.

## Key Highlights & Features
- **Hero Section**: High-performance hybrid seeds with farmer visual imagery and direct CTA buttons.
- **Why Choose Veda Seeds**: Science-backed research pillars (Research Driven, Farmer Focused, Quality Assured, Sustainable Future).
- **Featured Product Range**: Official Veda Seeds cotton hybrids:
  - **Platinum BG II** (PKCH 6836 BG II)
  - **Dr. Chandra Gold BG II** (PKCH 2043 BG II)
  - **Dharma Gold BG II**
- **Stats Strip**: Key impact metrics and operational footprint.
- **Research & Innovation**: Advanced breeding and field trial highlights.
- **Farmer Stories**: Testimonials from real Indian farmers with interactive carousel controls.
- **Interactive Animations**: Dynamic scroll reveals, 3D mouse tilt, and interactive badges.

## Tech Stack
- HTML5 (Semantic Structure)
- Vanilla CSS3 (Custom Design System, Responsive Layouts, Micro-interactions)
- Vanilla JavaScript (IntersectionObserver, 3D Tilt, Testimonial Carousel)
